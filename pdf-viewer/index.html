Help & guides

How to read, annotate, ask, and get back to work.

Getting started

Open a document — the big Open a PDF button on the home screen (or Ctrl+O, or the Volt ▾ menu → Open PDF…). In the desktop app this is the native file dialog, so the file you pick lands in Recent documents on the home screen — one click reopens it next time. You can also drag any .pdf onto the window, open a file from a URL (Volt ▾ → Open from URL…), or double-click a .pdf in Explorer if the file association is set up.

Try it — the Try the sample document link opens a short built-in essay so you can test reading, annotating, and AI chat with zero setup.

Layout — the sidebar (Pages / Outline / Notes) and the AI chat panel toggle with Ctrl+B and Ctrl+J; the AI panel's width is draggable (grab its left edge, double-click to reset). View ▸ switches between a dark and light skin (dark also inverts the document for night reading).

Everything is local and private — rendering happens on your machine, annotations autosave to this device, and the AI runs on your own local model or the API you configure.

Reading

Zoom — Ctrl + / Ctrl −, the toolbar zoom buttons, or W (fit width) / P (fit page). R rotates the page 90° at a time.

Navigate — scroll to move; ↑ / ↓ or PgUp / PgDn step page by page, Home / End jump to the first/last page. The sidebar's Pages tab shows live thumbnails (click to jump, drag to reorder, Shift+click to select a range).

Search — Ctrl+F, then Enter / Shift+Enter for next/previous match, Esc clears. Matches highlight in place as you type.

Select text — drag to select like any reader. Ctrl+A selects the whole page's text; Ctrl+A twice selects the entire document (small files render on demand). Ctrl+Shift+Home / End select to the document's start/end. Selections can be highlighted or asked about in the AI panel.

Annotating

All annotation tools live in the Markup ▸ menu. Pick a tool, then draw on the page.

Highlight / Underline / Strikethrough — drag over text (H / U / S). Dragging over blank space instead creates a free-form area highlight. Rectangle places a plain box (click for a fixed-size box, drag for a custom one, Alt+drag grows from the center, Shift+drag snaps to a square). Note (N) pins a comment.

Select mode (Esc) lets you edit what you drew: click an annotation to select it, then drag to move, use the handles to resize (area highlights get a rotate handle on top — or hold Ctrl while dragging), arrows nudge 1pt (Shift+arrows = 10pt), and Ctrl+D duplicates. Text highlights snap back onto their lines when you move them. Right-click an area highlight for color / delete.

Signatures — Markup ▸ Signature…: draw or type your name, save it, then click the page to place it (move/resize it afterwards like any annotation). Date stamp clicks today's date in. Form field… drags out a fillable text/date/checkbox/signature field; click a placed field in select mode to edit it.

Undo — Ctrl+Z / Ctrl+Shift+Z undoes/redoes annotation changes, including grouped ones. The Notes panel lists your notes; Clear highlights (AI panel footer) removes every highlight with a two-click confirm.

Pages

Manage pages… (sidebar, or Ctrl+Shift+P) opens the page manager: thumbnails with size and annotation badges. Click to select, Shift+click a range, Ctrl+A selects all, Ctrl+I inverts, Ctrl+Z / Ctrl+Shift+Z undo/redo staged edits before Apply.

Reorder — drag thumbnails (the drop bar shows exactly where they'll land) or use Move up / down / to… (the move form speaks plain positions: 3, before 4, after 2, or comma-separated). Home / End jump the selection to the start/end.

Delete / Insert / Blank stage changes into a plan — nothing touches the file until Apply. Inserting pages from another PDF reads that file's own annotations so the “from …” badges are accurate. Export selected… saves just the chosen pages as a new PDF. A rebuilt document keeps its annotations, renumbered to their new pages.

The sidebar thumbnails can reorder pages directly (drag, Shift+click to select a block); the change is undoable and, for a file opened from disk, written back to that file.

AI chat

Ctrl+J opens the AI panel. Ask anything about the document — answers are grounded in the actual text and cite ↗ p.N chips you can click to jump. Select some text and ask about it; the selection is passed along with your question.

Model — the header shows the active model. With no document open (or via the picker's ✎ global default…) you change the global default; each document can override its own model, max context, and system prompt from the · this doc marker (or ⚙ Settings). Persona presets (Legal, Beginner, Concise, or your own) swap a document's voice in one click; a global persona applies to every document.

First run — with no model configured, the panel shows a one-click setup card: it detects Ollama, offers the best installed model, or installs + pulls a small one for you. If a model is set but chat fails, check ⚙ Settings → the endpoint and model name.

Tools — the AI can act, not just answer: it gets tools to read pages, search, add/remove highlights and notes, navigate, and inspect annotations. Just ask (“highlight every mention of …” or “summarize page 3”).

Conversation — the transcript is capped at 40 messages by default (raise it to 100/250 in ⚙ → AI). Clear chat on the · this doc popover wipes a document's conversation; backups can carry the chat history too.

OCR

Scanned documents (images with no text layer) can be recognized in Volt — Tools ▸ OCR this document. Recognition runs locally via Tesseract.

Languages — Tools ▸ OCR language picks the recognition language (searchable, with download-on-demand). More languages download once and are cached on this device.

After OCR — the recognized words become a text layer: selectable and copyable like real text, findable with Ctrl+F, and readable by the AI. Toggle it with Tools ▸ OCR text layer. OCR text also powers restore-backup matching for scans, and can be exported as .txt / .md from the export menu.

Voice

Read aloud — Tools ▸ Read aloud (or the speaker button) reads the document with your machine's built-in voices — local, works offline. The read bar gives pause (Space), stop (Esc), and speed ±0.1.

Talk mode — the speaker toggle in the AI input row reads assistant replies aloud; while speaking, the floating bar gives Pause / Stop. Voice input — the mic button takes your question by speech.

Engines — ⚙ → Voice can point TTS and voice input at any OpenAI-compatible endpoint (a local Piper/Whisper server, hosted ElevenLabs/OpenAI, …) so the app stays small. Microphone and Speaker pickers let you choose audio devices — they apply to the external endpoints, since the built-in engines always use your system's default devices (change those in Windows Sound settings).

Files & backup

Export — Volt ▾ → Export / backup…: export the annotated PDF (marks burned in — form fields become real AcroForm widgets, signatures become images), a JSON backup, or a Markdown chat transcript. The backup dialog's checkboxes choose exactly what a backup carries: annotations, AI overrides (model/context/prompt), and chat history.

Restore — Restore a backup… (home screen or the export menu) picks a .json and matches it to the right PDF by a content fingerprint — so a renamed copy of the same file still matches, while a doctored file with identical size doesn't. Volt prompts you to open the matching document first. Restore backup from URL… runs the same flow from a .json link.

Disk watching — if the open file changes on disk (the author re-exported it), Volt offers a reload that preserves your scroll position and annotations.

Troubleshooting

“The AI isn't answering” — no model configured? The AI panel's setup card offers a one-click install. A model IS set but chat fails? Check ⚙ Settings → provider, base URL, model name, and API key; if you use Ollama, make sure it's running (ollama serve). The ⚙ Test connection button reports the exact failure.

“Ollama security warning” — if the panel warns that your Ollama allows wildcard origins, one click Restrict origins pins it to Volt so random web pages can't use your local model.

“Voice uses the wrong mic / speaker” — the built-in engines follow your Windows default devices; set them in Sound settings. The ⚙ → Voice device pickers apply to external TTS/STT endpoints.

“OCR didn't recognize my language” — Tools ▸ OCR language: search the language, let it download once, then run OCR again.

“A PDF won't open” — Volt reads .pdf files; corrupt or password-protected files can't be parsed. Files from URLs must be reachable (CORS) — the error toast explains why.

“The desktop app won't start” — the launcher shows an error window instead of a silent console. Re-run scripts/create-volt-shortcut.ps1 to rebuild the shortcut and file association. Volt ▾ → Check for updates verifies the bundle; vendored libraries update in the background after passing the smoke gate.

Welcome to Volt

Volt is a fast, private PDF reader with AI built in. Everything happens on your machine — rendering, annotations, and (optionally) your local AI. No account, no upsells. This one-time setup takes about a minute; you can change any of it later.

  • Annotate, sign, and fill forms — autosaved per document
  • Chat with the document through your own local model or an API
